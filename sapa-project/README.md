# NR Publicore — SAPA NR

โฟลเดอร์นี้เป็นตัวเว็บแอป React + Vite ของโครงการประชาธิปไตยดิจิทัลเพื่อการมีส่วนร่วม โรงเรียนนารีรัตน์จังหวัดแพร่

อ่าน **[คู่มือโปรเจกต์ฉบับเต็ม](../README.md)** สำหรับฟีเจอร์ โครงสร้าง การตั้งค่า Firebase และ environment variables โครงสร้างข้อมูล API ผลเลือกตั้ง และการ deploy

หลังตั้งค่า `.env.local` ตามคู่มือแล้ว ให้รันจากโฟลเดอร์นี้:

```bash
npm ci
npm run dev
```

คำสั่งเพิ่มเติม: `npm run lint`, `npm run build` และ `npm run preview`
